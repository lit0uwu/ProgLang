### Задание 3 **(2)**

*Рассмотрим следующую программу на языке С++.*

```

int main() {

int a=1, b=2;

int c=a+++b;

return 0; 

}

```

[int] [c] [=] [a] [++] [+] [b] [;]

Значение ```c``` выводит 3

По правилу максимального совпадения будет c = (a++) + b, инкремент постфиксный, в EAX лежит 1, получается 1 + 2

Изменить можно, вот так - ```int c = a + ++b;```
[int] [c] [=] [a] [+] [++] [b] [;]
выдаст что c теперь 4, инкремент префиксный, в EAX лежит 3, получается 1 + 3




### Задание 4 **(2)**

**Скобки являются операторами когда они выполняют вычисление**
- () как оператор - вызов функции или приведение типа.
- [] как оператор - доступ к элементу массива.

**Примеры фрагментов:**
- Является оператором: ```foo();``` - скобки оператор вызова, передают управление по адресу функции foo в памяти, после завершения - следующая инструкции программы.
- Не является оператором: ```if (x > 0)``` - просто обязательная часть разметки if, ```int x = (1 + 2) * 3;``` - разметка порядка математических операций.




### Задание 5 **(3)**

\*Рассмотрим следующую программу на языке Python.\*

```
print(*map(sum,zip(*[map(int,input().split()) for i in (1,2,3)])))
```

- **Ключевые слова:** for, in
- **Идентификаторы:** print, map, sum, zip, int, input, split, i
- **Литералы:** 1, 2, 3 (целочисленные)
- **Операторы:**
- ```
  * 
  ```
  (распаковка)
- = (внутри генератора списков for i in...)
- **Переменные:** i
- **Функции и методы:** print, map, sum, zip, int, input, split

Функции вызываются в следующем порядке (от внутренних к внешним):
1. input() — без параметров.
2. split() — метод строки, без параметров (разбивает по пробелам).
3. map(int, ...) — параметры: тип int и результат split().
4. zip(*...) — параметры: распакованный список из 3 сгенерированных итераторов map.
5. map(sum, ...) — параметры: функция sum и объект zip.
6. print(*...) — параметры: распакованный результат верхнего map.

- **Что делает**
1. Генератор списков трижды (for i in (1, 2, 3)) запрашивает строки через input(), режет их по пробелам через split() и преобразует элементы в числа через map(int, ...). Получается список из трех итераторов.
2. zip(*...) группирует элементы с одинаковыми индексами из этих трех строк (первые элементы вместе, вторые вместе и так далее — транспонирует матрицу).
3. Внешний map(sum, ...) считает сумму каждой полученной группы (складывает элементы в каждом столбце).print(*...) распаковывает и выводит итоговые суммы через пробел.

При вводе 
1 2 3
4 5 6
7 8 9 
Выводит
12 15 18

### Задание 7 **(4)**

**Цикл while**
- while ( condition ) statement
- Ключевое слово while, в круглых скобках условие condition, далее инструкция statement.

```
int x = 1;
while (x < 1000) {
    cout << x;
    x *= 2;
}
```

**Цикл do-while**
- do statement while ( expression ) ;
- Ключевое слово do, инструкция statement, ключевое слово while, в круглых скобках выражение expression, в конце точка с запятой ;.

```
int x = 1;
do {
    cout << x;
    x *= 2;
} while (x < 1000);
```

**Цикл for**
- for ( init-statement condition_opt ; expression_opt ) statement
- Ключевое слово for, в круглых скобках необязательное начальное выражение init-statement, необязательное условие condition, точка с запятой ;, необязательное выражение шага expression, далее инструкция statement.

```
for (int i = 0; i < 10; i++) {
    cout << i;
}
```

**Цикл for по диапазону**
- for ( for-range-declaration : for-range-initializer ) statement
- Ключевое слово for, в круглых скобках объявление переменной диапазона for-range-declaration, двоеточие :, инициализатор диапазона for-range-initializer, далее инструкция statement.

```
int arr[] = {1, 2, 3};
for (int x : arr) {
    cout << x;
}
```
