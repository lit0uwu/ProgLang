### Задание 2 **(2)**

**C++**

```

int main() {

int a=1, b=2;

int c=a++b;

return 0;  

}

```
Выводит - main.cpp:5:10: error: expected ‘,’ or ‘;’ before ‘b’

[int] [c] [=] [a] [++] [b] [;]

Склеивает знаки, получается a++ и отдельно b, а нужно чтобы между a и b был оператор.


**Python**

```

a=1

b=2

c=a++b

```
Выводит - пусто из исходного, если добавить print(c), то выводит - 3.

[c] [=] [a] [+] [+] [b]

Разбивает отдельно, так как в Python нет инкремента через ++ слитно, разбивает отдельно, что тоже самое что и a+(+b).

### Задание 3 **(2)**

*Рассмотрим следующую программу на языке С++.*

```

int main() {

int a=1, b=2;

int c=a+++b;

return 0; 

}

```

[int] [c] [=] [a] [++] [+] [b] [;]

Значение ```c``` выводит 3

По правилу максимального совпадения будет c = (a++) + b, инкремент постфиксный, в EAX лежит 1, получается 1 + 2

Изменить можно, вот так - ```int c = a + ++b;```
[int] [c] [=] [a] [+] [++] [b] [;]
выдаст что c теперь 4, инкремент префиксный, в EAX лежит 3, получается 1 + 3
